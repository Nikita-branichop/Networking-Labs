## Project 3: Inter-VLAN Routing (Connecting Two Offices)
**Goal:** Establish connectivity between two different subnets using a Cisco Router.

### Configuration Details:
* **Network A:** 192.168.1.0/24 (Gateway: 192.168.1.1)
* **Network B:** 192.168.2.0/24 (Gateway: 192.168.2.1)
* **Router Model:** Cisco 1941/4331

### What I learned:
* How to configure Router interfaces using CLI (`no shutdown`, `ip address`).
* The critical importance of the **Default Gateway** for inter-network communication.
* Troubleshooting connectivity issues using the `ping` command and Simulation Mode.

### Status: 
✅ Success. All PCs can now communicate across different subnets.

## Project 2: Office Star Topology with Cisco Switch
**Goal:** Connect multiple hosts using a central switch and host a local web service.

### Implementation:
* **Hardware:** 3 PCs, 1 Server, and 1 Cisco 2960 Switch.
* **Cabling:** Used **Straight-Through** cables for all connections (PC-to-Switch).
* **Services:** Enabled HTTP service on the Server.

### Results:
* Verified local connectivity between all PCs via `ping`.
* Successfully accessed the web server's default page from a client PC via Web Browser.
* Observed the STP (Spanning Tree Protocol) transition from amber to green light.
